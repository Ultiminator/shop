## Documentation

How to use it?
well you need to host it on a php server. if you don't have an actual server, you can convert your windows into a virtual server using programs like Winamp server.
just make sure that you have php and mysql installed.


### 1 -> host this folder on your server

### 2 -> create the database
use the file "Database.sql".
### 3 -> change variables
the fil "varaibles.php" contains the variables for the project.

what you have to change are the databse info: 
$mysqlHost,
$mysqlUser,
$mysqlPassword,
$dbName.

other vairable you can change if you want like the shop name, currency, contact info.
### 4 -> you can edit About info 
in the file "About/about.txt" which will b shown in About page
### 5 -> log in as admin
the site is ready open it whereever you hosted it. but it is empty.

use the link "$hostname/admins" to go to the amins page and start adding and editing items in the shop. the defaulf admin user name is "Admin" and password "12345678".

if you want to add anothr admin you will have to do it via database as there is currently no way to add it via the site.
